# Découverte de Laravel

##  1 : Introduction

- Un framework PHP pour créer des applications Web

**Oral :** « Je vais vous présenter Laravel, un outil pour développer des sites et applications Web. »

---

##  2 : Qu'est-ce que Laravel ?

- Un **framework** PHP open source
- Il fournit une structure et des outils prêts à l'emploi
- Le développeur n'a plus qu'à ajouter les fonctions propres à son projet

**Oral :** « Un framework, c'est une boîte à outils déjà organisée. Laravel ne crée pas le site à notre place, mais il gère les tâches habituelles. »

---

##  3 : Comment ça marche ?

Laravel suit le modèle **MVC** :

- **Modèle :** les données
- **Vue :** l'affichage
- **Contrôleur :** la logique qui relie les deux

```text
Navigateur → Route → Contrôleur → Modèle / Vue → Réponse
```

**Oral :** « La route reçoit la requête et appelle un contrôleur. Celui-ci récupère les données via le modèle, puis renvoie une vue au navigateur. »

---

##  4 : Avantages

- Gain de temps (routage, validation, base de données)
- Code organisé et facile à maintenir
- Outils de sécurité intégrés (CSRF, validation)
- Eloquent (accès aux données) et Artisan (commandes)

**Oral :** « L'intérêt principal est de ne pas repartir de zéro. »

---

##  5 : Utilisations et conclusion

- Sites Web dynamiques, boutiques en ligne, applications de gestion
- API pour applications mobiles

**Conclusion :** Laravel est un outil polyvalent pour développer des applications Web en PHP, à choisir selon le projet.

**Source :** [laravel.com/docs](https://laravel.com/docs)

**Oral :** « Laravel facilite le développement Web, des pages dynamiques aux API. Merci de votre attention. »
