# lab-php

## Objectif

Ce lab permet d'étudier et de mettre en pratique quatre notions permettant d'organiser le code d'une application PHP :

- **Architecture 3-tiers** : séparer l'application en trois parties : présentation, logique métier et accès aux données.
- **DAO (Data Access Object)** : séparer le code responsable de l'accès à la base de données.
- **Service** : organiser les traitements et les règles métier.
- **BaseService** : créer une classe commune pour partager les traitements entre plusieurs services.

Pour chaque notion, expliquer son rôle et réaliser un exemple pratique lié au projet et à son architecture.

## Travail demandé

1. Rechercher les quatre notions et expliquer leurs concepts clés.
2. Réaliser un exemple simple pour chacune dans le contexte du projet.
3. Tester les exemples pratiques et expliquer leur intégration à l'architecture.
4. Présenter les résultats dans `presentation.md`, au format Marp.

Les exemples, commandes et versions doivent correspondre à l'environnement réel du projet.
