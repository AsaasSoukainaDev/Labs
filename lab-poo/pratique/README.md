# Exercices pratiques de POO en PHP

Ce dossier contient un Hello World et un exemple autonome pour chacune des six notions du lab. Les exemples utilisent des articles fictifs en mémoire; ils illustrent la POO sans être intégrés à l'application Laravel.

Le projet de référence déclare PHP `^8.3` et Laravel `^13.17`. Les exercices ne requièrent que PHP CLI, sans framework, base de données ni dépendance Composer.

## Démarrage rapide

Depuis ce dossier, vérifier la version puis lancer le Hello World :

```powershell
php -v
php .\hello-world.php
```

Sortie attendue : `Hello, POO en PHP !`

## Exécuter les exemples

Depuis ce dossier :

```powershell
php .\classes-abstraites\exemple.php
php .\interfaces\exemple.php
php .\heritage\exemple.php
php .\polymorphisme\exemple.php
php .\encapsulation\exemple.php
php .\statique\exemple.php
```

Chaque notion possède un tutoriel pas à pas dans son sous-dossier.
