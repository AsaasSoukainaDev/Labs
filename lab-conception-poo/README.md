# lab-conception-poo

## 1. Besoin du projet technique

Ce lab a pour objectif de comprendre la **conception orientée objet (POO)** et d'apprendre comment préparer la structure d'une application avant de commencer à coder.

La conception POO consiste à analyser un besoin, identifier les classes nécessaires, définir leurs rôles et organiser leurs relations pour construire une application claire et facile à maintenir.

L'objectif est de découvrir le workflow de conception POO et de comprendre comment passer d'un besoin à une conception, puis à son développement.

### Projet technique

Pour mettre en pratique les connaissances acquises, nous allons concevoir et développer une application web de gestion de salle de sport.

L'application permettra de :
- Ajouter des disciplines sportives.
- Afficher la liste des disciplines enregistrées.

**Technologies utilisées :**
- **PHP** : développement de l'application en POO.
- **Tailwind CSS** : création d'une interface responsive.
- **UML** : représentation de la conception et des relations entre les classes.

## 2. Notions et techniques à apprendre

- **Conception orientée objet** : comprendre ce qu'est la conception POO, son importance et son rôle dans le développement d'une application.
- **Workflow de conception POO** : apprendre les étapes pour passer d'un besoin à une conception orientée objet.
- **Analyse et identification des classes** : comprendre comment analyser un besoin, identifier les classes nécessaires et définir leurs responsabilités.
- **Relations entre les classes** : comprendre comment organiser les relations et les interactions entre les classes.
- **Principes de conception** : découvrir les bonnes pratiques pour organiser le code, notamment la responsabilité unique, le faible couplage et la forte cohésion.
- **UML** : apprendre à représenter les classes et leurs relations à travers un diagramme de classes.
